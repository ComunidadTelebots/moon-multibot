# 🌙 Moon Multibot — AI Powered Telegram Ecosystem

Moon Multibot es un ecosistema avanzado de gestión de Telegram diseñado para ofrecer control total, inteligencia artificial contextual y seguridad de grado industrial en múltiples bots de forma simultánea.

## ✨ Características Principales

- **🎨 Glassmorphism 2.0 Dashboard**: Interfaz web ultra-moderna con telemetría en tiempo real.
- **🧠 Cerebro Híbrido (IA + RAG)**: Integración nativa con modelos de lenguaje y memoria contextual (Retrieval Augmented Generation).
- **🛡️ Neural Shield Security**: Auditoría avanzada, protección contra SPAM/Raid y escaneo de media mediante hashes SHA-256.
- **📊 Analíticas en Tiempo Real**: Monitorización de recursos y actividad mediante gráficos dinámicos (Chart.js).
- **🔌 Sistema de Plugins**: Arquitectura extensible con soporte para carga dinámica (Hot-Reload).

## 🚀 Instalación Rápida

1. Clona el repositorio:
   ```bash
   git clone https://github.com/TU_USUARIO/moon-multibot.git
   ```
2. Instala las dependencias:
   ```bash
   pip install -r requirements.txt
   ```
3. Configura tu entorno:
   - Crea un archivo `.env` o configura `data/bots.json`.
4. Inicia el núcleo:
   ```bash
   python moon_multibot.py
   ```

## 🛠️ Tecnologías

- **Backend**: Python 3.x, Flask, SQLite.
- **Frontend**: HTML5, Vanilla CSS (Glassmorphism), JavaScript.
- **IA**: Núcleo Markov nativo + Integración Gemini/OpenAI API.
- **Visualización**: Chart.js.
